# MiniBank Java Project

A simple banking application developed using Java.

## Features
- Create and display bank accounts
- Deposit and withdraw money
- Transfer money between accounts
- Calculate interest
- View transaction history
- Search and sort accounts
- Save and load account data
- Generate a text report

## Technologies
- Java
- Object-Oriented Programming
- Collections
- Exception Handling
- File Handling
- Multithreading

## How to Run
Compile: `javac MiniBank.java`

Run: `java MiniBank`
